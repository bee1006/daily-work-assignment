# Checkpoint: V2.2 每月出勤、每日工作總表與地圖預覽 (2026-11-16)

- **版本**: V2.2
- **主要更新**:
  1. 新增 `attendance.html`（「每月出勤」）：整合台灣 115／116 年官方國定假日與補假行事曆、人員異動管理（新增／移除／證照資格／排序）、雙擊編輯當日特別任務，並與派工任務雙向同步。
  2. 新增 `daily.html`（「每日工作」）：重現並強化出勤紀錄與驗收紀錄雙表，支援直接變更檢驗員、列印、備註記錄、天氣紀錄、深夜作業紅字黃底高亮，並可直接儲存變更至 Supabase。
  3. 升級 `coordinates.html`（「圖號座標」）：預設展開內嵌 Leaflet 地圖（國土測繪中心台灣電子地圖／衛星航照／OSM），定位確認後一鍵導航、查看街景或複製經緯度。
  4. 優化 `index.html`（「派工任務」）：更名「派工任務」，移除重複的卡片內 Supabase 登入面板，並支援讀取歷史與跨頁返回自動還原該日工作草案與單日安全合併（不覆蓋其他天出勤）。
  5. 新增 `version.js`：統一管理全站頂部導覽列版本標籤與雲端連線燈號，並統一四個頁面的「歷史查詢」按鈕樣式與字體。
