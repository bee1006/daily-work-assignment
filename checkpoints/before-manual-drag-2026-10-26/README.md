# 每日派工雛形

本機網頁第三版：上傳台電施工資料 Excel、選擇施工日期與輪替第一位同仁，依契約順序和資格規則分配工作，並直接將台電圖號解碼為 TWD67 TM2 座標；政府電桿 CSV 僅補充桿號資料。

## 啟動

需要 Python 3 與 `openpyxl`。在此資料夾開啟終端機後執行：

```sh
python3 -m pip install openpyxl
python3 app.py
```

接著瀏覽 `http://127.0.0.1:8000`。停止服務時，在終端機按 `Ctrl+C`。

## 目前規則

- 初始同仁順序依照提供的九人名單範例；新日期預設全員出勤 Y，僅第一位魏沐翔非關鍵性作業為 Y，監造證照則魏沐翔為無、其他人為有。可在「同仁名單管理」新增、移除、改名或調整順序；新增同仁預設出勤 Y、非關鍵性作業 N、監造證照有。
- 先依參考表排列 19 種契約；尚未列在順序表中的契約排在最後，並保留其在來源檔中的先後。
- 順序表前十項標示為 A 類；甲、乙、丙工區人手孔加固標示為 B 類；其他契約（包括新增或未列於表中的契約）標示為 C 類。
- 同一契約、同一工作班的多筆案件視為一組工作，且每組只會指派給一位同仁；同組案件不會拆給不同人。A 類每人最多一組、C 類每人最多三組；超出限制時標示待人工指派，不重複指派。
- 出勤與非關鍵性作業狀態按派工日期分別儲存在瀏覽器；證照屬於固定人員資料。缺勤者跳過，非關鍵性作業為 Y 的同仁只會分配 C 類，B 類只分給有監造證照者；沒有合適人選時標示「待人工指派」。
- 從「工作內容」及「施工地點」擷取完整 9 碼或 11 碼台電圖號座標，同一案件的重複座標只列一次。地點中接續前一座標的短碼（例如 `AD30`）會以前一座標的前 5 碼補全，並以箭頭標示，供人工核對。
- 圖號中的空白及零寬空白會在比對前移除；每筆工作第一個辨識到的圖號標為代表定位點，類別間距離初篩只使用各筆工作的代表點。像「共 189 處」這類多點工作會以代表點作初始定位，實際點位仍需依現場安排。
- 台電圖號依其編碼直接換算成 TWD67 TM2 格網中心點，與 `all.csv` 是否收錄無關；9 碼約 10 公尺、11 碼約 1 公尺。`all.csv` 只用於補充電桿桿號、行政區等資訊，因此配電場所圖號也能參與距離計算。
- 派工依使用者定義的負載級別平衡：單一 A、B、C 為第一級；A+C、B+C、2C 為第二級；A+B、B+2C、2B、3C 為第三級；A+B+C 為第四級。對未列組合以相同級距延伸規則比較。先選加派後級別最低者，同級才比工作點直線距離，仍同級則依輪替起點。出勤、非關鍵性作業和監造證照為硬性資格；A 類不能分給非關鍵性作業 Y 的同仁，B 類僅分給有證照者，C 類可分給所有出勤者。此版本只按工作組數估負載，尚未納入案件工時、工項難度或實際道路里程。
- A＋B 優先鄰近配對試行規則：所選日期的 A/B 工作組數大於或等於出勤且可執行關鍵作業（非關鍵性作業 N）的人數時，啟用優先配對。系統先從 A、B 工作組中找代表點距離在併派門檻內的組合，依距離由近到遠嘗試讓同一位合資格同仁承接一組 A 與一組 B；該同仁需出勤、可執行關鍵作業且具 B 類監造資格，仍受距離及每人最多一組 A 的限制。無法成功配對的工作再按原本單組規則分派，之後才處理 C 類候選包，讓有空間的同仁仍可承接 C 類工作。檢核區會顯示門檻及成功配對數，工作卡會標示 A＋B 兩組間的最遠代表點直線距離。
- 上傳後先按契約順序列出工作組、類別、代表圖號和可換算點位數。C 類以工作組間最遠代表點直線距離找附近候選包，預設門檻 10 公里且每包最多 2 組；缺少座標的工作不會自動合包。派工時距離門檻是硬限制：同仁已有工作時，新工作組的所有代表點必須與該同仁每一組既有工作的代表點都在門檻內；任何點位超距或無法核實時，不會派給該同仁。剔除超距人選後先比較負載級別；同級時選較近者，再按輪替順序。尚未分到工作的合格同仁可接沒有附近既有人選的工作。附近 C 類候選包整包交給同一人，必須同時符合資格、每人最多 3 組 C 類及負載規則。若沒有合適人選，工作／整包待人工指派，不會超距或拆分。距離為直線距離，並非車程。
- 每位同仁摘要會顯示 A↔B、A↔C、B↔C（同類有多組時也顯示同類點位）最近直線距離，並列出以 A 類優先、後續採最近點的建議工作順序及每一相鄰工作組距離。距離使用各來源案件的代表圖號；同一工作組內若有案件沒有可換算圖號，會在派工檢核列出，不會默默忽略。這是直線距離，不代表實際行車路線。
- 派工結果增加按同仁彙整的工作卡，列出工作班、工作內容、施工地點、圖號及換算座標。政府電桿資料不包含道路路網，因此目前尚未計算實際車程距離。
- Excel 原始日期為民國年時會轉成西元日期處理，網頁仍以民國日期顯示。
- 名單與每日狀態存在目前瀏覽器的本機儲存空間；上傳內容交由本機 Python 程序讀取，不傳送到外部服務。

`all.csv` 僅有電桿資料，無法定位配電室等未收錄點位，也不含道路路網。實際車程需要另外提供本機道路路網與路線引擎，或選擇會傳送工址座標的外部路線服務；目前尚未匯出派工結果。
