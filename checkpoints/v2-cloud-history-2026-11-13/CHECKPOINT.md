# Checkpoint: V2 雲端歷史直讀版本 (2026-11-13)

- **版本**: V2
- **主要更新**:
  1. 頂部橫幅「歷史查詢」按鈕與連線指示燈。
  2. 新增「☁ 雲端派工歷史查詢」彈出面板（Modal），支援 Supabase 登入與直接讀取歷史派工紀錄。
  3. 無需上傳 Excel，可直接選取歷史日期還原派工卡片、名單出勤設定、建議巡檢路線與圖號座標。
  4. 第一步匯入施工資料卡片增加快速查詢指引條。
  5. `coordinates.html` 導覽列同步支援一鍵跳轉開啟歷史查詢。
  6. `app.py` 增強 `openpyxl` 容錯導入，確保無 Excel 解析依賴時亦能正常啟動並提供雲端服務。
